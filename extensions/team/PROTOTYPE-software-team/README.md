Throwaway. This is a draft for the human to react to, written for the wayfinder ticket
[Draft a software-team Playbook and a sample Brief](https://github.com/hoangtmbk/pi-config/issues/83).
It is not the extension. It lives on the `prototype/software-team-playbook` branch and is never merged.

```
teams/software/                      as it would ship in extensions/team/teams/software/
  team.md
  roles/architect.md, dev.md, qa.md
  default-playbook.md
efforts/sample-web-fetch-cache/      as it would sit in ~/.pi/agent/team/efforts/<id>/

  clarifications.md
```

The layout, frontmatter fields and file names come from
[How Teams, Roles and Playbooks are defined](https://github.com/hoangtmbk/pi-config/issues/80) and
[Teammate permission policy](https://github.com/hoangtmbk/pi-config/issues/81). Everything else in
these files is new, and is the part to react to.
